# 复赛验收记录

日期：2026-10-19。沿用原赛题、原项目。本记录仅描述本轮实测，不替代赛方最终验收。

## 2026-10-20 产品体验与真实连续使用

### 配图后的连续润色

- 用独立测试稿和之前真实生成的行李场景 PNG 复现了问题：只改语气后，稿件版本增加，但场景图未重新绑定，页面不再显示该图。
- 改为比较新旧稿件的使用场景，只改语气、纠错、精简且用途仍匹配时，保留已选文件与摘要并绑定新版；直接编辑同样处理。换产品、换场景或没有平台图片空间时不盲目沿用，不触发生图购买。
- 创建时的场景描述只作为使用意图参考，不冒充实际画面复核。保留的图仍受会话、版本和文件摘要约束；独立产品事实检查照常执行，生成图不成为产品事实证据。
- 当前全量自动检查为358项通过，类型检查与独立生产构建通过。真实手机页面连续测试语气改稿、直接编辑与换场景：前两者保留同一场景图摘要、导出及刷新一致；从差旅改为固定居家办公后，旧行李场景图不再出现在新版，旧地址不再提供该图。此处使用已生成素材的测试副本，没有重新购买图片；不把它算作新的生图样例。
- 材料核对发现说明书开头和边界段仍残留“331项、完整生成待验收”的旧状态，已与当前实测统一。三组复赛优秀成果、新版PDF及连续录屏仍须另行完成，未在此宣称交付。

### 图库优先与 Qwen 辅助场景图

- 独立配置 Qwen 图片服务，不覆盖 DeepSeek 文字模型设置；密钥与生成文件仅写本机私密目录，已确认被 Git 排除。
- 已有稿件可对话补图或点击“补充配图”。先重新读取本型号图库，匹配现有图则复用；故障不当作缺图，不触发生成。没有合适环境图且用户允许时才生成一张无品牌、无电子设备的环境插画；默认新稿仍只使用图库。
- 生成图单独标明 AI 来源，不是产品事实、官方产品图或“已人工复核”画面；不补足缺少真实产品图的缺口，合计数量不超过平台限制。支持实际下载和移除，补图或移除均产生新版并重新检查。
- 生成文件保存不可覆盖的本地 PNG，取图绑定会话、当前稿件版本及 SHA256。取消后迟到结果不能提交，检查失败保留原稿；改稿后只有经用途判断并绑定新版的场景图才进入导出，文件丢失或变化时拒绝导出。
- 用真实 Qwen 模型 `qwen-image-2.0-pro-2026-06-22` 生成差旅行李环境插画，并在手机页面完成对话补图、加载、下载、刷新和移除。两张图库产品图与正文保持不变；下载的 PNG 摘要与保存记录一致。已实际打开该图查看，画面为衣物、旅行包和纸笔，没有设备或品牌产品；页面未因此显示过程日志。
- 串测曾发现“写新稿，只用现有图库”被错当成单独补图。已把写稿、改稿与单独配图区分为互斥意图，写稿条件不能覆盖主要任务；新增回归并重新实测原写稿流程。
- 本轮全量自动检查为356项通过；32个流式浏览器场景、10个导出场景及独立生产构建通过。真实模型流程与接口模拟场景分别记录，不合并成“所有场景都已通过”。

### 导出与直接编辑的连续使用补充

- 实际复现了同会话旧导出晚于改稿返回、随后复制到旧正文的问题。现在导出请求独立绑定当前操作及稿件版本，改稿、恢复和新创作均使旧请求失效；传输忽略取消也无法覆盖新版内容。
- 导出准备时有简短提示并阻止重复点击；失败与重试按钮留在同一侧栏，不把错误丢到被遮住的聊天区。错误版本、空正文不提供复制与下载。
- 增加直接下载正文 TXT，文件名使用已导出版本；可选来源清单只包含稿件、图片和引用信息，不再把调用日志与内部报告混入发布文件。
- 补齐服务端边界：报告失败但未返回具体问题时，接口仍拒绝导出；不能因问题列表为空而放行。
- 新增 10 个真实浏览器页面场景（电脑/手机各 5，接口模拟），覆盖迟到导出、失败与重试、版本冲突、正文实际下载、来源文件不含日志、直接编辑后立即点导出，以及另一页面保存新版后先恢复新版再重试导出。另用真实保存的第 2 版 Pro S 稿件，在手机页面点击导出与下载，逐字比对 TXT 与实际接口正文一致，共 2 张图库配图；该步骤没有重新调用模型。
- 实际直接编辑后点击导出时，会先保存修改；保存期间无法导出旧版，结束后再次点击可导出当前版。

- 按用户要求移除页面内的行动链、模型与资料调用卡、缓存/耗时/字符计数，以及选购端检索过程面板。内部记录保留，不在主界面展示。
- SSE 从模型请求贯穿到浏览器，普通创作聊天与无产品候选的咨询也持续显示公开回复文字；不显示内部推演或 JSON。保留停止、迟到事件隔离与断线后只查询恢复。
- 完成消息改为自然交付语句；刷新恢复统一措辞。仅本轮实际产生新稿时保存交付消息，普通聊天不重复追加旧稿完成状态；失败报告不以零问题冒充成功。
- 真实 DeepSeek 调用曾出现隐藏思考耗尽输出预算、回复截断后重试。已针对官方 DeepSeek 地址和当前模型关闭默认思考模式，将预算留给正式输出；其他网关不发送此专用设置。原有独立事实检查继续执行。
- 真实使用发现“不写优惠和亲测”被当成缺少依据的要求，增加了无用解释；已区分写作偏好和要求添加的内容。减少资料不足的重复提醒，保留真正影响发布的缺图提示。
- 真实手机改稿发现“只留一个参数”仍罗列多个版本重量。将本轮修改要求放到资料之后，提高其优先级，允许删除旧主张及引用；再次实测只保留一组明确版本的重量值。版本提示改为自然中文，正文不出现 SKU 行话；画布图注不再展示“导语后”等编辑位置。
- 修正当前稿件使用目录编号时产品下拉框仍显示“先聊需求”的问题。补充消息后流式区增高时，手机保持正文与输入框可见，并允许向上阅读历史。
- 完成 344 项自动检查、类型检查与正式构建；另有 32 个真实浏览器页面场景通过，接口全部模拟，覆盖电脑/手机、流式替换、停止、断线、旧会话隔离、恢复、导出。

## 已验收的基础能力

- 创作端内部保留步骤、资料和模型调用记录，页面只展示回复与稿件，支持SSE及原NDJSON协议。草稿待核验时不能假装通过；执行结束与稿件核验分别判断。
- 停止任务按会话和运行编号匹配，先确认请求，再确认结束。支持超时、模型调用次数限制和迟到结果隔离。
- 双端记录保存至本机私密目录，刷新后读取已保存状态；断开页面不自动停止或重新生成。重启中的未完成任务标为中断。
- 写盘失败回滚至最后成功保存的内容。模拟结束时磁盘写满，恢复存储后，通过查询或下一次提交均可解除孤立忙碌锁；存储仍异常时返回错误。
- 导出仅含本会话调用，核验必须对应当前稿件版本。不同Windows大小写编号不能绕开同一任务锁。
- 选购端提供SSE进度、停止确认、服务端最近12轮记录恢复；客户端仅提交新问题，不提交助手历史。新旧任务及双端相同编号互相隔离，旧浏览器记录仅供只读查看。
- 选购端默认只展示建议与候选，需要时可展开产品资料；内部保留检索来源与范围。产品精确资料与全库发现结果分开处理；混合检索中的图片不会导致整批文字被拒绝。查看原文先读取单份元数据并核对摘要，无需下载全部目录。
- 收尾保存也纳入任务锁，连续查询与第二次提交不会被旧任务误覆盖。创作与咨询均通过20轮原问题复现检查。
- 知识库适配器与可公开的本地混合检索源码已整理，支持来源标识、资料指纹、按登记编号读原文和异常反馈。
