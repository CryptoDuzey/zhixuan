# 迭代报告：价格与对话体验

## 1. 靶点与诊断证据

本次按独立小轮处理问题，没有将价格检索、页面措辞和界面状态当成一个实验计分。

- 价格上下文：固定六题的 baseline 中，agent-pair-2 只覆盖两款中的一款，agent-pair-3 漏掉已有防窥款报价。原记录在 output/iterations/price-context-baseline-20261023。
- 页面实测：比较 Pro S 与 D 14 后追问“那 D 14 的 24GB/512GB 呢？别拿其他配置的价格代替。”，仍要求完整型号；简称承接失败。另历史金额行显示“当前商城页面价”，与末尾历史说明矛盾。
- 独立窗口审查发现写稿失败留下无法收起的空工作台、历史界面最多200条、新建咨询沿用旧平台。原复现与疑点分别保存于 output/iterations/experience-review-20261023/report.md。

## 2. 假设与实验设计

价格轮假设：从服务端保留角色的用户历史解析型号，对各产品分别读取价格卡，可补齐比较时漏掉的产品及已有报价，不让模型自行重选范围。使用原六题，不改题句；两次后测，要求型号与原始配置、日期、来源一致，不能套用缺配置记录。

简称轮假设：仅在此前用户明确提到的范围中，唯一短名也可承接。新增固定实际失败句，与无前文、跨年份两个对照；先记录失败再修改。成功标准：该追问正确识别D14；两个歧义对照不私选型号；既有用例无退化。

措辞轮仅修改显示：历史卡“当前”显示为“当时”，不修改原证据；下架结论明确限定为资料记录。界面状态问题独立修复与验证，不计入价格效果。

## 3. 结果与失败变化

原六题两次后测均实现：双产品覆盖1/2→2/2；已有防窥历史报价找回0/1→1/1；两条D14指定容量仍不套用5799元参考起价。指定柔光配置的当前价仍为0/1，不能称全部询价任务完成。完整只读复核在 output/iterations/price-context-review-20261023/report.md。

简称实际失败句由要求重报型号，改为正确回答D14缺少该配置报价；这属于上下文修复，不是新增价格数据。相关26项检查通过，记录见 experience-integration-20261023/short-name-{baseline,after}.log。

页面重新构建后，实际询问Pro S 24GB/512GB柔光款，返回9999元“当时商城页面价”，注明2026-10-17及不代表当前成交价。旧保存消息保留原样，没有改写失败历史。新建、类别、示例切换、刷新恢复均已实际操作；页面文字与截图保存于 experience-integration-20261023/shopping-ui-after.*。

界面审查测试最初断言“缺陷存在”，通过不代表产品通过；修复后须保留基线并转为正确行为回归。最终检查数字以同目录 final-tests.log 为准，不能把跳过或TODO算通过。

## 4. 固化决定

保留产品身份与独立报价改动；保留限定范围的简称承接和历史措辞修复。规则写入 app/AGENTS.md。已有失败实验和原六题结果不覆盖、不改分。历史分页与界面状态修复以独立窗口的报告和最终构建验证为准。

## 5. 元反思与下一靶点

用户会使用简称、连续追问和省略条件，原固定六题仍不充分；应持续加入真实失败样本，并保留原样本作回归。型号正确、历史报价正确、如实说明缺口、取得具体配置现价必须分开统计。

创作事实审查仍有漏检与潜在误报：不能将更严格阻止导出当作事实判断更准确。混合索引覆盖15468片段只证明结构覆盖，不能证明语义检索完整；图库映射不等于所有图片已逐张目视验证。继续优先处理这些有失败证据的问题，尚不能宣称所有任务都已可靠或赛事材料全部完成。

### 本轮新增的真实创作失败

会话 `s-b9fcb221-8ec5-4848-80b7-0eeb680f4109`：两轮普通聊天均未展开画布；第三轮明确进入任务，要求Pro S朋友圈正文60至100字、无价格、仅有依据的特点及一张库图。生成及一次篇幅补救后仍触发篇幅失败，没有交付稿件。完整输入和失败状态已保存为 `output/iterations/experience-integration-20261023/creation-ui-failure-full-session.json`，页面观察保存在同目录 `creation-ui-failure.txt`。不计为成功创作或配图成功。

此样本还实际复现了失败后空画布残留；刷新可回到单栏，但原地应自动回收，故修复结束事件在无稿件时收起画布。已有稿件必须保留。下一轮应先补充不含凭证的候选正文计字记录，诊断篇幅补救为什么失效；现有运行记录没有保存被拒绝的候选正文，不能凭猜测扩写提示词。恢复文案也改为区分“已有稿件”和“只有对话”，避免误称恢复了不存在的稿件。
