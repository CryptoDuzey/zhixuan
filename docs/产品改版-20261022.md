# 知选产品改版与验收（2026-10-22）

本轮依据用户最新10项要求直接执行。普通对话入口要简单，创作和选购面向不同用户；本地知识库可先直接使用，产品图取知识库；有明确创作任务后才打开工作台；支持空间调整、会话保存和真实多轮问答。最新本地优先要求覆盖此前将ima在线列为立即阻塞的计划，但不会把本地调用标成在线调用。

## 设计与分工

- 主窗口：创作页、普通聊天/任务画布切换、可拖动分隔线、历史共享界面、全局视觉和最终合并验收。
- 选购窗口：独立选购入口、自然输入、浮动产品展示、类别与示例问题轮转，保留原SSE/恢复/取消/来源。
- 会话窗口：只读历史列表与分页，原两端私密记录仍是权威，前端不导入服务端模块。
- 知识库窗口：本地全量目录、索引指纹、混合检索和图库覆盖实测。

视觉采用暖纸白、深灰和克制华为红；一张生成的抽象纸带图仅作界面背景，产品图不生成。活动文字标明参赛作品，不声称这是主办方官方产品。无工具日志、行动链、密钥或后台实现文案。

## 参考与架构边界

已查阅[DeepSeek Harness官方核心架构](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/core/README.md)：会话、工具、提示、agent循环分别组织，历史从持久化会话派生。本项目沿用现有本地记录与运行保护，补上会话发现与切换，不安装另一套通用执行器，也不声称已经迁移为其插件架构。

## 固定验收

1. 两个入口均无“先聊需求，再选产品”“平台随需求判断”和强制选择框。
2. 创作端连续普通聊天两句不显示稿件画布；明确写稿后才显示，成稿、改稿和导出仍可用。
3. 拖动/键盘调整分隔线有效，刷新保留；窄屏没有横向遮挡，输入与停止按钮可用。
4. 新对话、历史列表、选择旧对话、刷新恢复，创作/选购互相隔离；正在运行不能误切换污染状态。
5. 选购类别、产品卡、示例问题轮转均可键盘操作，产品图实际加载且来自本地资料。
6. 原固定价格/联网失败保留，新增缓存修复两轮实际HTTP回归；不把参考价冒充配置价。
7. 本地索引文件/片段/指纹一致、固定问题真实命中原文，未命中如实记录；topK不等于全库穷尽。
8. 全量检查、类型与构建、真实浏览器和真实模型分别记载；发现已知失败仍红，不能只选通过批次。
