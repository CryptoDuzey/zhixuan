# 三分钟演示

1. 打开创作端。输入“你好”，展示先问用途与产品，没有默认 Pro S。
2. 选择 D 14，输入“面向大学生，先核对课程软件和外设，写一条朋友圈，不写价格”。等待真实生成与核验。
3. 看真实产品图、版本条件、原文依据。输入“更像朋友提醒，减少推销感”，展示重新核验后导出。
4. 切到“选购”。输入“大学学习，预算6000，Windows Office，比较D14和MateBook14酷睿Ultra，先给方案，不报价”。展示任务建议、产品取舍及依据。
5. 选中候选，点击“带到创作端”，确认产品与场景已带入。
6. 展示作品说明书中的公众号和独立图文创作示例，明确不同示例的生成来源。

录屏时不要展示密钥输入过程。不要中途重启服务；已有会话先导出。
