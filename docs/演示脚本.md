# 复赛三分钟演示脚本（待真实彩排）

更新：2026-10-20。下面是正式录屏的计划操作，不是已完成的三分钟录屏。当前已实际跑通聊天、选购、图库写稿、手机改稿、导出、刷新及辅助配图；开始录屏前仍需确认实际知识库和模型状态，并用同一版本彩排一次。

1. 打开创作端。输入“你好”，展示自然对话，没有默认选中某一产品或固定五款菜单。
2. 选择 D 14，输入“面向大学生，先核对课程软件和外设，写一条朋友圈，不写价格”。等待真实生成与核验。
3. 看真实产品图、版本条件、原文依据。输入“更像朋友提醒，减少推销感”，等待新版重新核验；只有当前稿满足导出条件时才导出。生成预览不算完整稿，检查未结束不称完成。
4. 切到“选购”。输入“大学学习，预算6000，Windows Office，比较D14和MateBook14酷睿Ultra，先给方案，不报价”。展示任务建议、产品取舍及依据。
5. 选中具备专用素材映射的候选，点击“带到创作端”，核对任务、受众、约束和平台后开始独立创作。当前一键交接对这些映射产品开放，不能据此宣称全部目录产品均可一键交接。
6. 展示作品说明书中的公众号和独立图文创作示例，明确不同示例的生成来源。

可选配图演示：在已有稿件中点击“补充配图”，或描述缺少的环境图。先说明优先选图库；确实需要生成时，展示明确标注的辅助场景图、保存图片和移除操作。不要把生成图称作真实产品图，不必每次录屏都重新生图。

录屏时不要展示密钥输入过程。不要中途重启服务；已有会话先导出。

另作可靠性彩排：生成中刷新后查询当前任务、主动停止后确认不再更新、完成后刷新恢复原稿；将预算和用途改成相反条件后检查新版，确认旧条件已撤回。任何一步失败，保留实际错误和待解决项，不把历史优秀稿或独立内容示例当作本次运行结果。
