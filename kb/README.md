# 知选本地知识库

本仓库提供产品事实、官方公开价格记录、图片与图片索引、场景、写作方法、培训及常见问题资料。克隆后在仓库根目录运行：

```sh
node scripts/start-knowledge.mjs
```

默认从相邻的 `华为PC全板块深度知识库_v7` 目录读取，只监听本机8765端口。设置 `ZHIXUAN_KB_DIR` 可换用自己的目录，`IMA_LOCAL_PORT` 可指定其他端口。应用通过 `IMA_BASE` 连接资料服务，默认地址已匹配。

公开版包含1502个文件（约33.7MB），不包含 `P4-价格政策库（机密）` 的20份文件。原资料根目录的统计、导航及哈希清单描述原始完整版本；公开版范围以实际文件为准。P1中的官方公开价格快照仍保留，使用时区分日期、配置、参考价格与实际购买价格。

资料保留原始来源链接、日期、型号及适用条件。图片和引用材料权利归原权利人，本仓库的代码发布不改变第三方素材授权；对外商用或再次分发时按原来源和适用授权处理。教学场景不代表真实客户成果。

基础目录读取、文字检索、原文及图片读取无需向量模型。可选的混合检索运行方式见 [检索说明](../scripts/rag/README.md)，模型权重和运行缓存需在本机准备，不随资料上传。模型服务密钥与用户会话仍保存于私密目录，不属于知识库。
